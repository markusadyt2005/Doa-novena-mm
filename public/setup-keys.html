RUANG NOVENA · PENGATURAN PENGELOLA

Siapkan kunci pengingat.

Halaman ini membuat kunci secara lokal di browsermu. Tidak ada nilai yang dikirim ke server atau disimpan otomatis. Buat sekali, lalu salin ke Environment Variables Vercel.

Jika kedua iPhone sudah terdaftar, gunakan pasangan kunci lama. Mengganti kunci mengharuskan keduanya mengaktifkan ulang pengingat.

Simpan ketiganya di Vercel untuk Production, lalu redeploy. Jangan unggah private key atau cron secret ke GitHub. Nilai di halaman ini akan hilang setelah dimuat ulang atau ditutup.
